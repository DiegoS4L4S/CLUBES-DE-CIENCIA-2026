# CLUB AGS 2 - "DEL MICRÓFONO AL CEREBRO ARTIFICIAL: ¡JARVIS, ESTOY MOLESTO!"

**Clubes de Ciencias 2026 - Proyecto de Cómputo Afectivo**

## Descripción
Jarvis es un prototipo web y de hardware de bajo costo desarrollado para detectar violencia doméstica verbal a tiempo. El sistema analiza el tono, volumen, velocidad y timbre de la voz para reconocer el enojo humano antes de que escale a agresión física. El procesamiento ocurre localmente (Edge AI) preservando la privacidad del usuario.

Esta página web interactiva documenta el funcionamiento, la arquitectura de hardware y la ciencia acústica detrás del proyecto.

## 🛠️ Tecnologías y Componentes

**Hardware:**
*   ESP32-S3-N16R8 (Microcontrolador)
*   INMP441 (Micrófono I2S)
*   MAX7219 (Matriz LED 8x8)
*   Buzzer Activo

**Software e IA:**
*   MicroLightCNN (Red Neuronal Convolucional)
*   Procesamiento de Señales de Audio (MFCC, FFT, Filtros Mel)
*   Desarrollo Web (HTML5, CSS3, JavaScript, GitHub Pages)

## 🚀 Uso y Demostración
El prototipo web es una aplicación interactiva orientada a dispositivos móviles. Incluye un *Enojómetro* funcional que simula la respuesta de la red neuronal al alterar el tono y volumen de la voz.
